# График смен — Android

Первая версия приложения хранит все данные локально на телефоне.

## Что уже есть
- Автоматический циклический график (по умолчанию 2/2)
- Дата начала первой рабочей смены
- Перелистывание месяцев кнопками и свайпом
- Ручное изменение конкретного дня: рабочий / выходной / вернуть по графику
- Подработка: часы + индивидуальный коэффициент
- Расчёт подработки: оклад / число основных смен месяца / 8 * коэффициент * часы
- Халтура: название фирмы + необязательная сумма оплаты
- Комментарий к любому дню
- Настраиваемые цвета для смены, подработки и халтуры
- Месячная сводка
- Локальное хранение через SharedPreferences
- GitHub Actions workflow для сборки debug APK

## Сборка
GitHub Actions автоматически выполняет:

    gradle :app:assembleDebug

Результат:
`app/build/outputs/apk/debug/app-debug.apk`

## Минимальная версия Android
Android 7.0 (API 24) и новее.
